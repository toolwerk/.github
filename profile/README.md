# toolwerk

🇩🇪 **Helfer für die Arbeit und für zuhause.**
[Sven](https://github.com/mahype), [Simon](https://github.com/iappwebdev) und [Frank](https://github.com/staude) veröffentlichen hier die kleinen Werkzeuge, die sie sich selbst gebaut haben: schlank, lokal und gut dokumentiert.

🇬🇧 **Helpers for work and home.**
[Sven](https://github.com/mahype), [Simon](https://github.com/iappwebdev) and [Frank](https://github.com/staude) publish the small tools they built for themselves: lean, local-first and well documented.

## Projekte · Projects

| Projekt · Project | 🇩🇪 Worum es geht | 🇬🇧 What it does | Stack |
|---|---|---|---|
| [**MicLED**](https://github.com/toolwerk/micled) | Die Luxafor-Lampe zeigt, wann du auf Sendung bist: Mikrofon, Kamera, Timer, Slack-Status, Home Assistant. | Your Luxafor light shows when you're on air: microphone, camera, focus timer, Slack status, Home Assistant. | Rust · Swift · macOS |
| [**Rackmon**](https://github.com/toolwerk/rackmon) | Ein kleines Display im Rack zeigt, wie es deinen Rechnern gerade geht: Agenten für Linux, macOS und Windows, ein Server, ein Streifen-Dashboard. | A small display in your rack shows how your machines are doing: agents for Linux, macOS and Windows, one server, one strip dashboard. | Go · Linux · macOS · Windows |
| [**Kastellan**](https://github.com/toolwerk/kastellan) | Gibt KI-Assistenten Zugriff auf deine Hoster, ohne ihnen die Schlüssel zu geben: Postfächer, DNS, Datenbanken und Server bei sieben Anbietern, Rechte pro Assistent, Freigabe für alles Heikle, Protokoll. | Gives AI assistants access to your hosting providers without handing them the keys: mailboxes, DNS, databases and servers at seven providers, permissions per assistant, approval for anything risky, audit log. | Swift · MCP · macOS · Linux · Windows |
| [**amiscara-ssh**](https://github.com/toolwerk/amiscara-ssh) | Gemeinsamer SSH-Client der Amiscara-Apps als Rust-Bibliothek: Host-Key-Prüfung, Schlüssel, Shell mit PTY, Jump-Hosts, Agent-Forwarding und SFTP, gebaut auf russh. | Shared SSH client of the Amiscara apps as a Rust library: host key verification, keys, shell with PTY, jump hosts, agent forwarding and SFTP, built on russh. | Rust · russh |
| [**lbmute**](https://github.com/toolwerk/lbmute) | Schaltet den Eingang eines einzelnen Audiogeräts stumm, etwa eines Loopback-Geräts, ohne das echte Mikrofon anzufassen: ein Kommandozeilenwerkzeug für Sprachchat und Diktat. | Mutes the input of a single audio device, such as a Loopback device, without touching the real microphone: a command-line tool for voice chat and dictation. | Swift · Core Audio · macOS |
| [**toolwerk-ui**](https://github.com/toolwerk/toolwerk-ui) 🚧 | *In Arbeit.* Gemeinsame Gestaltungsregeln für die Oberflächen der Werkzeuge: Web-UI-Richtlinie mit Theme, Bausteinen und einer Referenzseite. | *Work in progress.* Shared design rules for the tools' interfaces: a web UI guide with theme, components and a reference page. | daisyUI · Tailwind CSS |
| [**Flowcus**](https://github.com/toolwerk/flowcus) | Claude-Code-Plugin für den Issue-Workflow: Skills vom Issue bis zum PR-Review, dazu Herdr-Plugins fürs Team. | Claude Code plugin for the issue workflow: skills from issue to PR review, plus Herdr plugins for the team. | JavaScript · Claude Code · Herdr |

## Grundsätze · Principles

| | 🇩🇪 | 🇬🇧 |
|---|---|---|
| 🔒 | **Lokal zuerst**: Daten bleiben auf deinem Gerät, Zugangsdaten im Schlüsselbund. | **Local first**: your data stays on your device, credentials in the keychain. |
| 🧩 | **Offen anbindbar**: Kommandozeile, URL-Schema, Webhooks und Kurzbefehle. | **Open to integrate**: command line, URL scheme, webhooks and Shortcuts. |
| 🧪 | **Getestet**: die Logik in einem getesteten Kern, die Oberfläche dünn. | **Tested**: logic lives in a tested core, the UI stays thin. |
| 📖 | **Dokumentiert**: Einrichtung, Aufbau und Grenzen stehen im README. | **Documented**: setup, architecture and limits are in the README. |
