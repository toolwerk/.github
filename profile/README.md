## Grundsätze · Principles

| | 🇩🇪 | 🇬🇧 |
|---|---|---|
| 🔒 | **Lokal zuerst**: Daten bleiben auf deinem Gerät, Zugangsdaten im Schlüsselbund. | **Local first**: your data stays on your device, credentials in the keychain. |
| 🧩 | **Offen anbindbar**: Kommandozeile, URL-Schema, Webhooks und Kurzbefehle. | **Open to integrate**: command line, URL scheme, webhooks and Shortcuts. |
| 🧪 | **Getestet**: die Logik in einem getesteten Kern, die Oberfläche dünn. | **Tested**: logic lives in a tested core, the UI stays thin. |
| 📖 | **Dokumentiert**: Einrichtung, Aufbau und Grenzen stehen im README. | **Documented**: setup, architecture and limits are in the README. |
